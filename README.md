# Village Math Quest

Build the ML-Based Gamified Adaptive Mathematics Learning Platform where students learn mathematics through adaptive challenges and a village-building game.

Start with Module 1: Platform Setup, User Onboarding, Student Profile, Mathematics Course Selection, and the Initial Diagnostic Test.

Key requirements for this initial phase:
- User onboarding: Registration/login simulation, student profile setup (grade/curriculum level, village name, avatar).
- Course selection: Mathematics domains (Arithmetic & Number Operations, Pre-Algebra, Geometry, Data & Statistics).
- Diagnostic assessment engine: A comprehensive multi-topic diagnostic test evaluating baseline competencies across topics with easy, medium, and hard difficulty questions.
- Telemetry tracking: Track response times, attempts, hints, and correctness to feed into the student's baseline feature profile.
- Diagnostic analysis: Analyze topic-by-topic performance, identify weak and strong areas, and compute initial mastery levels.
- Personalized learning path generation: Display the student's baseline knowledge profile and recommend their starting learning path.
- Gamification setup: Award starter XP, coins, and a first diagnostic badge, laying the groundwork for village building.
- Engaging, modern educational UI with clear mathematical formatting and interactive feedback.
